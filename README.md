# Для Полины

Маленький сайт с цветами, милыми словами и играми. Всё в одном файле — `index.html`, без сборки.

- **Посмотреть локально:** просто открой `index.html` в браузере.
- **Опубликовать:** Settings → Pages → Source: «Deploy from a branch», ветка с этим файлом, папка `/ (root)`.
- **Поменять тексты** (комплименты, письмо, подпись): объект `CONFIG` в начале `<script>` в `index.html`.
